## 1. Визуальное обновление (CSS и UI)

### 1.1 Цветовая схема в стиле Python

- **Тёмная тема:** глубокий тёмно-синий фон вместо чёрного, акценты — небесно-голубой и золотистый
- **Светлая тема:** светло-серый/белый фон, акценты — насыщенный синий (Python Blue) и мягкий жёлтый
- **Цвета:**
  - Основной синий: `#3776AB` (официальный цвет Python) — кнопки, навигация
  - Акцентный голубой: `#4B8BBE` — ссылки, активные модули
  - Золотой: `#FFE873` — точечно (иконки достижений, кнопка «Купить/Начать»)

**Реализация:** создать `variables.css` (или блок в существующем CSS) с CSS-переменными для `:root` (тёмная тема) и для класса `.light-theme`. Все цвета брать из переменных, чтобы при переключении темы менялось только значение переменных.

### 1.2 Время в шапке (navbar)

- **Вариант 1 — часы:** в шапке отображать актуальное время пользователя (через JavaScript, без перезагрузки страницы)
- **Вариант 3 — последнее обновление:** показывать, как давно обновлялся контент курса (например: «Обновлено 2 дня назад»), чтобы сайт выглядел «живым»
- Сделать аккуратно и актуально; для международной аудитории можно учитывать часовой пояс (UTC или локальный)

## 2. Реорганизация контента (модели и логика)

### 2.1 Структура курсов

- Оставить модель `Course`, но перейти к **двум курсам:**
  - **Python для начинающих (Junior):** основы, логика, циклы
  - **Python для профессионалов (Pro):** Flask, Flask API, Django, деплой на сервере
- В модели курса добавить поле **level** (Новичок / Профи) или использовать отдельные записи в БД
- Для уроков и модулей добавить поле **order** (порядковый номер), чтобы отображать их строго друг за другом

### 2.2 Rich Text для уроков

- Подключить **django-markdownx** или **django-ckeditor**, чтобы в админке можно было писать уроки с:
  - блоками кода Python с подсветкой
  - таблицами, списками, заголовками
- Обычного `TextField` недостаточно для «расписать все подробно»

### 2.3 Медиа-файлы (картинки)

- На Render файлы в `media/` удаляются (эпизодический диск). Подключить **Cloudinary** через **django-storages**.
- В моделях уроков (или курсов) использовать `ImageField`; настройки хранилища направить на Cloudinary, чтобы картинки хранились в облаке и не пропадали после деплоя.

## 3. Интеллектуальные функции (ИИ и чат-бот)

### 3.1 Контекстный помощник (Gemini)

- Настроить промпт так, чтобы ИИ знал: «Ты — ассистент курса Python. Помогай ученику с кодом и теорией».
- Уже есть `GEMINI_API_KEY` — использовать его.

### 3.2 Улучшения для «качественного ИИ»

- **Streaming:** ответы печатаются постепенно, а не одним блоком.
- **History:** сохранять историю диалога (в БД), чтобы бот «помнил» предыдущие сообщения в сессии.
- Реализовать отдельную страницу или виджет чата (например, в углу экрана).

### 3.3 Ограничения по подписке

- **Бесплатные пользователи:** например, 3 запроса к ИИ в день.
- **Платные (is_premium):** безлимит.
- (Опционально) Кнопка «Проверить мой код» — отправка кода ученика в Gemini для разбора ошибок.

## 4. Монетизация (платный курс 4$)

### 4.1 Система доступа (Paywall)

- В модели профиля (например, `users/models.py`) добавить поле **has_access** или **is_premium** (`BooleanField`, по умолчанию `False`).
- **Бесплатные уроки:** первые 2–3 урока каждого курса открыты всем.
- **Платные уроки:** при переходе на урок проверять `has_access`; если `False` — редирект на страницу оплаты.

### 4.2 Приём платежей

- **Цена:** 4$ (удобный порог для первой продажи).
- **Для мира / Европы:** **Stripe** — поддержка Apple Pay, Visa, Mastercard, хорошая интеграция с Django (например, `dj-stripe` или официальная библиотека `stripe`).
- **Для РФ/СНГ:** отдельный шлюз (ЮKassa, Robokassa и т.п.), так как Stripe не работает с российскими банками.
- **Webhook:** создать в Django URL, на который платёжная система пришлёт уведомление «Оплата успешна»; в обработчике менять `has_access` на `True` для пользователя.

### 4.3 Добавление ценности

- **Сертификат:** после прохождения курса генерировать PDF-сертификат (библиотеки для PDF в Python есть).
- (Опционально) Таймер в стиле FOMO: «До конца акции (4$ вместо 10$) осталось: HH:MM:SS» — только если планируется акция.

## 5. Юридическая защита

- **Публичная оферта (Public Offer):** страница с текстом вида «Вы платите 4$ за доступ к обучающим материалам» — что именно получает пользователь и на каких условиях.
- **Политика конфиденциальности (Privacy Policy):** что происходит с email и персональными данными, что ты не передаёшь их спамерам.
- Разместить ссылки на эти страницы в футере (и при необходимости на странице оплаты).

---

## 6. Языки (i18n)

- Поддержка трёх языков: **русский, английский, итальянский**.
- В `settings.py`:
  - `LANGUAGE_CODE = 'ru'` (или по умолчанию)
  - `LANGUAGES = [('ru', 'Русский'), ('en', 'English'), ('it', 'Italiano')]`
  - В `MIDDLEWARE` добавить `django.middleware.locale.LocaleMiddleware`.
- В шаблонах обернуть строки в `{% trans "..." %}` (или `{% translate %}`); выполнить `makemessages`, заполнить `.po` файлы переводами, затем `compilemessages`.
- В шапке сайта — переключатель языка (флаги или выпадающий список).

## 7. Профиль пользователя (расширение)

- В модели профиля (например, `Profile` в `users/models.py`) иметь или добавить:
  - **has_access** / **is_premium** — доступ к платному контенту после оплаты.
  - **language_pref** (опционально) — предпочтительный язык пользователя.
- При создании суперпользователя через `create_superuser_if_missing` при необходимости создавать и связанный `Profile`.

## 8. Техническая оптимизация (Render и деплой)

- **База данных:** на бесплатном Render БД может иметь ограничения по сроку жизни. Подключить внешнюю PostgreSQL (например, Neon.tech), прописать `DATABASE_URL` в Environment на Render — данные будут храниться постоянно.
- **Статика и медиа:** статика уже через WhiteNoise; медиа после настройки Cloudinary уйдут в облако, на диске Render ничего критичного не остаётся.
- **Переменные окружения:** все секреты (ключи API, Stripe, ЮKassa и т.д.) хранить только в Environment на Render и в локальном `.env`, не коммитить в репозиторий.

## 9.1. Идеи «на потом» (после запуска платной версии)

## 10. Нюансы из переписки (кратко)

- **Конкуренты и блокировки:** не копировать чужой контент, не использовать чужие товарные знаки; честная выдача доступа после оплаты и оферта снижают риски.
- **Актуальность для СНГ и Европы:** 4$ — низкий порог; для Европы можно указывать время в UTC; ИИ (Gemini) может отвечать на языке пользователя.
- **Мультивалютность:** Stripe для международных карт и Apple Pay; для РФ — отдельный платёжный шлюз.
- **Профиль:** в коде от Gemini была опечатка `on_on_delete` — правильно `on_delete` при определении ForeignKey/OneToOneField.
